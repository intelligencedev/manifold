# Prompt: Crawl Repository

Use this prompt to refresh the wiki evidence:

1. List top-level files and directories.
2. Inspect docs, manifests, build files, deployment config, tests, and entrypoints.
3. Map package boundaries and major symbols.
4. Extract route maps, tool names, store schemas, frontend routes, and Makefile targets.
5. Record direct evidence in `wiki/evidence.md`.
6. Label inferences and unknowns separately.
